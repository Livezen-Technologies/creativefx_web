# Certification logos

Drop the official artwork here and the Compliance & certifications marquee
(Our Story) swaps the wordmark badge for the logo automatically — no code
change needed.

File name = the certification name lowercased with non-alphanumerics turned
into hyphens. Any of .svg .png .webp .jpg are picked up (SVG preferred).

Current items and the file names they look for:

| Shown as     | File name          |
|--------------|--------------------|
| SMETA        | `smeta.jpg`        |
| BSCI         | `bsci.jpg`         |
| SEDEX        | `sedex.jpg`        |
| OEKO-TEX     | `oeko-tex.jpg`     |
| HIGG         | `higg.jpg`         |
| GRS          | `grs.jpg`          |
| GOTS         | `gots.jpg`         |
| OCS 100      | `ocs-100.jpg`      |
| ISO 14064-1  | `iso-14064-1.jpg`  |
| LEED Gold    | `leed-gold.jpg`    |

Logos render on a white card, so supply transparent or white-background
artwork. Add or rename items in the Our Story page content and the expected
file name follows the same slug rule.
